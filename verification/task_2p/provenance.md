## 2. Exact `vector_mismatches` Computation Definition (A5)

- **Reference Source:** Local cached passage matrix `eval/.cache/llama-text-embed-v2/passages.npy` (L2-normalized `float32`, shape `(16833, 1024)`), aligned row-by-row with `data/disastermind_snapshot.parquet`.
- **No Re-Embed Used ($0 / 0 tokens):** `run_full_d1_d5_verification()` did NOT call the Pinecone inference `/embed` API to reconstruct reference vectors during the 16,833-vector parity audit (`0` verification embedding tokens spent). Instead, it fetched every stored vector (`index.fetch`, 100 IDs/request, 169 requests total) from Pinecone and compared it against the exact matrix row that had been sent during ingestion.
- **Exact Check & Tolerance (`scripts/ingest_pinecone.py` lines 472–479):**
  1. Convert fetched values to `arr_f = np.asarray(f_vals, dtype=np.float32)`.
  2. Fail (`vector_mismatches += 1`) if `len(arr_f) != 1024` or `not np.all(np.isfinite(arr_f))`.
  3. Normalize fetched vector `arr_f / np.linalg.norm(arr_f)` (`float32`), compute dot product `cos = float(np.dot(..., ref_arr))` against `ref_arr` (`passages.npy` L2-normalized `float32`).
  4. Fail (`vector_mismatches += 1`) if `cos < 0.9999` (tolerance allows `1e-4` aggregate angular slack for JSON ASCII float round-trip precision). Result across all `16,833` vectors: `vector_mismatches = 0`.
